# Installing Jenkins & ZeroTier on Local Ubuntu Server
This article will explain steps to installing Jenkins & ZeroTier on local Ubuntu server. 

Welcome! My name is Zaki, I am currently studying DevOps Seroiously :D

This article aims to help anyone who wants to learn Jenkins at a low cost or even for free. This article segmented in 3 segment :

# 1. Prerequisites

- Download ISO Ubuntu Server 22 Link : https://ubuntu.com/download/server
- Download Ventoy, Link : https://sourceforge.net/projects/ventoy/files/v1.1.07
- Flashdisk minimal 8 GB
- Old PC, for my experiment i user an old cpu with intel-core i3 gen 6 and RAM 4 GB.

The spesification for Jenkins is :
Minimum hardware requirements:
- 256 MB of RAM
- 1 GB of drive space (although 10 GB is a recommended minimum if running Jenkins as a Docker container)

Recommended hardware configuration for a small team:
- 4 GB+ of RAM
- 50 GB+ of drive space

# 2. Installing Ubuntu Server

- First you need to make bootable usb using ventoy, you can see this tutorial : https://winpoin.com/cara-membuat-bootable-windows-10-dengan-ventoy/
- Make sure you change Windows 10 ISO with ubuntu server ISO
- Then try to boot usb drive with old PC, after that you must install ubuntu server in your old PC, you can see this tutorial : https://www.youtube.com/watch?v=n7aEcfDNULc
